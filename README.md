# LAB02
ARREGLOS Y EXCEPCIONES 
Una agencia espacial universitaria se encuentra preparando una misión de exploración hacia una 
región desconocida del espacio. Para realizar la misión, una nave deberá contar con diferentes 
módulos que permitan ejecutar funciones como navegación, comunicación, generación de energía 
y análisis científico. 
La nave posee una cantidad limitada de espacios físicos para instalar módulos. Por esta razón, la 
cantidad máxima de módulos es conocida desde el inicio y deberá administrarse utilizando un 
arreglo básico. 
Durante la misión también se descubrirán nuevos planetas. Debido a que no se conoce 
previamente cuántos planetas podrán encontrarse, estos deberán almacenarse utilizando un 
ArrayList.
